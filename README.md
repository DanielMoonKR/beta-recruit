# 땡큐캠핑 리뉴얼 베타 테스터 모집 페이지

정적 웹페이지입니다. GitHub Pages로 배포합니다.

- 공개 주소: https://danielmoonkr.github.io/beta-recruit/
- 신청: 네이버 폼 (https://naver.me/Ix0Mlh7W)

## 파일 구성
- `index.html` : 페이지 전체(문구, 디자인, 동작)
- `assets/` : 로고, 목업 이미지, 공유 미리보기 이미지, 폰트(Pretendard, OFL 라이선스), 실행 스크립트

## 수정하는 법
1. 수정된 `index.html`(또는 `assets` 안의 파일)을 받는다.
2. 레포 첫 화면 → Add file → Upload files → 같은 이름의 파일을 끌어다 놓는다.
3. Commit changes → 1~3분 뒤 공개 주소에 자동 반영된다.
